# Professional Organizer Fort Smith Website

A conversion-optimized Next.js 14 website for a professional organizing business in Fort Smith, Arkansas.

## 🎨 Brand Colors

- **Primary (Serene Blue)**: #4A90A4
- **Secondary (Sage Green)**: #8BA888
- **Accent (Warm Terracotta)**: #C97C5D
- **Background (Soft Cream)**: #F5F1E8
- **Text (Charcoal Gray)**: #2D3436
- **Borders (Light Gray)**: #DFE6E9

## 🚀 Getting Started

### Development Server

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```

## 📱 Pages

- **Homepage** (`/`) - Conversion-optimized hero with 4-U formula headline
- **Services** (`/services`) - Service overview
- **Service Details** (`/services/[service]`) - Individual service pages
- **Pricing** (`/pricing`) - Transparent pricing packages
- **Portfolio** (`/portfolio`) - Project showcase
- **About** (`/about`) - Company information
- **Contact** (`/contact`) - Contact form with validation
- **Blog** (`/blog`) - Blog home and article pages

## ✨ Hero Section Features

### Conversion Optimization

- **4-U Formula Headline**: Useful, Unique, Urgent, Ultra-specific
- **Problem-Focused Subheadline**: Addresses customer pain points
- **First-Person CTA Psychology**: "Get MY Free Consultation"
- **Trust Signals**: 50+ 5-Star Reviews, Licensed & Insured, Satisfaction Guaranteed, NAPO Member
- **Full-Screen Hero**: 100vh on desktop, auto on mobile
- **Smooth Animations**: Scroll indicator, hover effects, button transforms

### Design Elements

- Serene Blue gradient background
- White text for high contrast (WCAG AA compliant)
- Warm Terracotta CTA buttons
- Semi-transparent trust signal badges
- Responsive typography (32px mobile / 48px desktop)
- Animated bouncing scroll indicator
